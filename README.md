# rclone-autark

Two static pages, served by GitHub Pages, that Google requires before it lets the off-site backup's
OAuth app (project `autark-offsite-261114b`) be published. They hold no secrets and no backups.

- Home page: `index.html`
- Privacy policy: `privacy.html`

The source of truth is Gitea (`bill/rclone-autark`); GitHub (`williamblair333/rclone-autark`) is a push
mirror for Pages. See autark's `docs/runbooks/offsite.md`, step 4.
